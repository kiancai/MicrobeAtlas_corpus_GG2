## 4. GMrepo / mBodyMap 覆盖（纯 metadata 富集，不加样本行）

| 库 | 总 run | **可贴(∩五库)** | 贴不上(无序列) | 主要落在 |
|---|---:|---:|---:|---|
| **mBodyMap** | 63,148 | **60,479 (95.8%)** | 2,669 | MA 60,398 · RM 9,997 · MBM 48 |
| **GMrepo** | 118,865 | **39,007 (32.8%)** | 79,858 | MA 32,392 · MBM 9,347 · Qiita 3,792 · PRIME 215 · RM 41 |

> 各库分项之和 > 可贴数：同一 run 可同时在 MA∩RM 等，分项非互斥。

- **GMrepo ∩ mBodyMap = 0**（实测确认；同组按部位互补切开，故意不重叠）。
- **可被富集的语料样本（去重）= 99,486**；**同时被两库贴的 = 0**（run 不相交）→ 两库间**无直接 metadata 冲突**。
- "重复"性质：这 99,486 样本在**母库（MA/RM/MBM/PRIME/Qiita）已自带 metadata**；GMrepo/mBodyMap 强项（部位/疾病/性别/地理，尤其 MA 部位弱）是**补充** → 按列级合并原则作 `GMREPO_`/`MBODY_` 前缀并入，**不覆盖母库公共列**。
- GMrepo/mBodyMap 自身只下到 metadata CSV（GMrepo 丰度 keyed NCBI taxon 且无序列）→ **0 净新增样本行**，纯富集。

## 5. 口径警告（落地前必读）

1. **Run 字面重叠 = 下界**：同一生物样本换 accession 重测/重处理则匹配不上 → **BioSample 级去重会更多**，留 Layer2 精算（GMrepo/mBodyMap/各库都有 `sample_id`=BioSample 可用）。
2. **Qiita 74,148 无 run**：计为净新增，但"真净新"无法用 run 验证（可能经 biosample 撞）→ Layer2 标 `dedup_uncertain`。
3. **重叠 = 待去重标记，非删除**：沿用 `Run_paired_id` 保留两份带 `Database` 标签（merge-then-filter）。
4. **MA 覆盖率 = 时间快照效应**：MA 抓取停在 ≈2021-01；净新增集中在 2021 后资源（Qiita/PRIME/MBM）。见 `pipeline_audit_microbeatlas.md`。

## 5b. 旧 QC(v1) 对五库的实测影响（2026-06-05，脚本 `/tmp/qc_impact.py`/`qc_crossdb.py`）

旧 QC v1：删 shallow var → 迭代删 prevalence==0 var + 删样本（**深层 reads<1000 OR 深层属<5**）。
**注：已定 QC=打标不删（见 `merge_architecture.md`），下表仅为"若按旧 QC 会删多少"的体检。**

| 库 | 行数 | 按 QC 会删 | 删率 | 会留 |
|---|---:|---:|---:|---:|
| MA | 2,690,735 | 928,100 | 34.5% | 1,762,635 ✓ |
| RM | 100,391 | 6,966 | 6.9% | 93,425 ✓ |
| MBM | 168,464 | 10,158 | 6.0% | 158,306 |
| PRIME | 53,449 | 6,910 | 12.9% | 46,539 |
| Qiita | 321,502 | 48,993 | 15.2% | 272,509 |
| **合计(按行)** | **3,334,541** | **1,001,127** | **30.0%** | **2,333,414** |

> MA 留 1,762,635 / RM 留 93,425 与已知 `gg2.full.qc`/`resmicrodb.qc` **逐字吻合** → QC 复刻正确。
> 主因 = 测序/注释太浅（深层 reads<1000）；其中 **MA 315,226 样本深层 reads=0**（全 reads 落浅层/被清）。

**跨库 QC 判决（2,923,879 唯一 run）**：全通过 1,959,224 · 全失败 916,129 · **★判决分歧 48,526**（某库删、另一库留）。
→ 这 48,526 正是"全留不删"相对 per-DB QC **救回**的样本，是 QC=打标不删的实测依据。

## 6. 关键结论（一句话）

- 整合后**合并宇宙 ≈ 300 万唯一样本（pre-QC）**；MA 是基底，四库净增 ≈ 30.7 万 run（+ Qiita 7.4 万无 run）。
- **已覆盖 MGnify 88.7%** → MGnify 无需并入。
- **mBodyMap 95.8% / GMrepo 32.8%** 可贴 metadata 富集；两库互补不冲突，纯富集 0 加行。
